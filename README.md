# placefolio.github.io

Static GitHub Pages blog for Placefolio.

## Structure

- `index.html`: homepage
- `posts/index.html`: post archive
- `posts/<slug>/index.html`: article pages
- `styles/site.css`: shared styles

## Publish

1. Push to `main`
2. In GitHub, open `Settings > Pages`
3. Set source to `Deploy from a branch`
4. Select `main` and `/ (root)`

The site will publish at `https://placefolio.github.io/`.
